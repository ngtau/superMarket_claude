## 七、本次核对后的未完成清单（按优先级）

### P0 —— 阻塞上线
1. **Playwright E2E**：SDRS §14 要求关键流（注册→浏览→加购→结算→支付→发货→查单）有 E2E 覆盖，目前仍是占位。前端页面现已齐备，具备接入条件。
2. **数据库连接串与迁移**：`DATABASE_URL` 仍为占位值，需真实 Neon/Supabase/RDS 实例后执行 `db:generate`/`db:migrate`/`db:seed`。

### P1 —— 上线前应处理
3. **vike PDP SSR/ISR（D7）**：本次只补了 robots/sitemap/JSON-LD。SPA 下 JSON-LD 是客户端注入，对不执行 JS 的爬虫不可见——这属于过渡方案，正式方案需 PDP 走 SSR。
4. **数据备份实际导出**：`POST /admin/backups/trigger` 目前只写一条 `pending://` 记录，真实 PITR + 定时 JSON 导出需部署环境。
5. **xlsx 批量导入导出**：v1 先落 CSV（DoD 原文为 xlsx/csv）。需引入 exceljs 等依赖。
6. **访问与转化统计**：依赖 GA4，目前返回结构化占位。

### P2 —— 可延后
7. 商品销量排序 `sort=sales` 当前以创建时间兜底（未做订单聚合）。
8. 运费拆包裹计费（多商品命中不同模板时不拆分计费，SDRS 未要求）。
9. 折扣挂商品级而非 SKU 级（同一商品所有 SKU 共享折扣）。
10. Grafana Cloud / Loki 接入、Cloudflare 反代 + 自定义域、GitHub Actions 实际跑通、回滚演练 —— 均需真实账号与环境。

> 详细建议与决策说明见同目录《后续开发建议与变更说明_v1.md》。
