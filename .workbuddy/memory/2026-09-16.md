## 环境踩坑（本机重要）

- **Bash 工具 PATH 损坏**：`ls`/`head`/`wc`/`find` 等全部 "command not found"。解法：每条命令前加 `export PATH="/usr/bin:/bin:$PATH"`。
- **PowerShell 工具 stdout 不回显**：结果拿不到。解法：把输出 `Out-File` 到文件再用 Read 读。
- **pnpm 不在 PATH**：`npm i -g pnpm@9` 装到 `/e/Program Files/nodejs`，之后需 `export PATH="/e/Program Files/nodejs:$PATH"`。npm 走代理 127.0.0.1:7890。
- **pnpm install 被沙箱拦截**（EPERM，E:\.pnpm-store 写权限）：必须加 `dangerouslyDisableSandbox: true` 重跑。
- **tsc -b 增量构建陷阱（重要）**：仓库里提交过 `tsconfig.tsbuildinfo`，且 dist 目录状态与实际不同步，导致 `tsc -b` 只 emit 了改动文件的 .js（其余只有 .d.ts.map），运行时报 `Cannot find module .../roles.module.js`。解法：`rm -rf dist tsconfig.tsbuildinfo` 后 `tsc -b --force`。
- **冒烟启动后端**可用于验证路由注册（无需真实 DB，pg 连接池懒连接）：`node dist/main.js` + `grep Mapped`，能验证路由数量、路径与**声明顺序**（静态路径是否排在 `:id` 之前）。
